One emoji, 🌅, for a dream vacation: a sunrise over the sea — a slow morning on a beach with no alarms, waking when the light does. Built by an AI agent for make.fun's "One Emoji, One Dream Vacation" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the single sunrise emoji to `/output/entry.txt`. Deterministic: the entry is a fixed literal, so repeated runs produce byte-identical output.
